# Bank--Loan--Analysis

Bank Loan Analytics Dashboard | Power BI

1. Project Overview

The Bank Loan Analytics Dashboard is an end-to-end data analytics project developed using Microsoft Power BI to analyze loan applications, funding activities, repayment performance, and overall lending operations. The project transforms raw loan data into meaningful insights through interactive dashboards, KPIs, charts, and filters.

The dashboard helps stakeholders understand loan portfolio performance, identify lending trends, monitor financial metrics, and make data-driven decisions.

2. Problem Statement

Financial institutions handle large volumes of loan application data, making it difficult to efficiently monitor loan performance, repayment activities, and lending trends. Without a centralized analytical dashboard, identifying good and bad loans, tracking key financial indicators, and understanding borrower behavior can be challenging.

This project aims to develop an interactive Bank Loan Analytics Dashboard using Power BI to analyze loan portfolio performance, monitor key performance indicators (KPIs), evaluate repayment behavior, and identify trends across loan categories, loan purposes, and borrower characteristics.

3. Project Objectives

- Analyze overall loan portfolio performance and lending operations.
- Track total loan applications and funded amounts.
- Monitor total amount received through loan repayments.
- Compare good loans and bad loans.
- Analyze loan status and repayment behavior.
- Evaluate average interest rates and Debt-to-Income (DTI) ratios.
- Identify monthly loan application trends.
- Analyze loan distribution by purpose, home ownership, and loan term.
- Perform regional analysis of loan applications.
- Provide interactive visualizations for data-driven decision-making.

4. Key Performance Indicators (KPIs)

The dashboard focuses on the following KPIs:

- Total Loan Applications: Total number of loan applications received during a specified period.
- Total Funded Amount: Total amount of money disbursed by the bank as loans.
- Total Amount Received: Total amount received from borrowers through repayments.
- Average Interest Rate: Average interest rate across all loans.
- Average Debt-to-Income (DTI) Ratio: Average ratio of borrowers' debt obligations to their income.

6. Filters and Navigation

Interactive filters and navigation features are included to improve dashboard usability.

- Purpose Filter: Analyze loans based on their purpose.
- Grade Filter: Compare loan performance across different loan grades.
- Page Navigation Buttons: Navigate between different dashboard pages.
- Reset Filters Button: Reset applied filters and return to the default dashboard view.

8. Key Insights

The dashboard is designed to help users:

- Understand loan application and funding trends.
- Compare repayment amounts with funded amounts.
- Identify the distribution of good and bad loans.
- Evaluate loan performance across different statuses and grades.
- Analyze borrower characteristics and loan purposes.
- Monitor interest rates and DTI ratios.

9. Project Outcome

This project demonstrates how business intelligence and data visualization can transform raw financial data into actionable insights. The interactive dashboard provides a structured view of loan performance, lending trends, repayment activities, and portfolio-level KPIs to support informed decision-making.

10. Conclusion

The Bank Loan Analytics Dashboard provides an interactive and comprehensive view of banking loan operations. By combining KPIs, charts, filters, and navigation features, the project enables users to explore loan data effectively and better understand lending performance and repayment trends.
